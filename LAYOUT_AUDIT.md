# Premium Editorial Layout Audit

## Core hierarchy

- Project title: 72–96 px (responsive within the fixed A4 landscape canvas)
- Category: 22 px
- Narrative paragraph: 17 px, within the requested 16–18 px range
- Section rhythm: 120 px
- Project-element rhythm: 80 px
- Text rhythm: 40 px

## Grid translation

The supplied block sketch is interpreted as a twelve-column, five-row editorial system:

1. Full-width title band
2. Split feature band with a deliberate central gutter
3. Full-width artwork or divider band
4. Narrow narrative band
5. Asymmetric image-and-copy closing band

Project openers and rationale pages use the full hierarchy. Artwork-led evidence, gallery, newspaper and poster pages use a compact caption variant so the original work remains visible and uncropped.

## Art-direction rules

- Keep artwork colours, crops and composition intact.
- Use the portfolio cream, ink, ochre and project-specific accent colours.
- Align titles, categories, paragraphs and footers to the twelve-column system.
- Avoid placing body copy over detailed artwork.
- Preserve consistent running headers and footers from beginning to end.
- Treat project colour as a local accent, not a replacement for the portfolio identity.
